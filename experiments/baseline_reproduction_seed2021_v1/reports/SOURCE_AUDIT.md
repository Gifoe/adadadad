# Source and protocol decisions

- LatentTSF official commit: 7c8ae947ee1220bf4e788ace6bc2f0f122cb26c2. AE files are Git-tracked official pretrained weights, not retrained. Full forecast uses my_train.py, my_AE.py and official DLinear/iTransformer. Official shell AE path includes an extra dataset-type token and does not match shipped directories; wrapper selects the unique tracked checkpoint for each dataset. Loss is latent elementwise MSE plus cosine averaged over flattened batch/time rows (per-time cosine). Official LayerNorm option remains disabled. MAE references are read from Table 6, correcting the task's Table 7 reference.
- DAG official commit: 0758990e2c73bb54138ea3e7b11a35cbc5476bcc. Previous checkpoint reuse is permitted only after source, command, data SHA, scalers, origins, predictions and independent metrics match. The original split uses two floors: train_valid=floor(N*.8), train=floor(train_valid*.875). This yields 36690/41932/52416 boundaries, rather than naive floor(N*.7). Training drop_last is True; test drop_last False. Official published TCM/CCM and future-exog controls retained.
- WorldTS released team source: 269426ea6217d7152a244da0e209d922acd46d4f, released 2026-10-09. Use its DAG-bench numerical branch and published NP/PJM commands. Source ownership is the same decisionintelligence team as DAG; README identifies the WorldTS implementation. All WorldTS architecture and train hyperparameters are now OFFICIAL_SOURCE. This supersedes the task's independent-reproduction fallback and unknown hyperparameter assumptions. No arbitrary latent_dim=128 for PJM: source uses 224. Preflight checks operate on the official classes.

Sources: [LatentTSF source](https://github.com/Muyiiiii/LatentTSF/tree/7c8ae947ee1220bf4e788ace6bc2f0f122cb26c2), [LatentTSF paper](https://arxiv.org/html/2602.00297v1), [DAG source](https://github.com/decisionintelligence/DAG/tree/0758990e2c73bb54138ea3e7b11a35cbc5476bcc), [WorldTS source](https://github.com/decisionintelligence/WorldTS/tree/269426ea6217d7152a244da0e209d922acd46d4f), [WorldTS paper](https://arxiv.org/html/2609.31162v1).

Protocol commitments are frozen before WorldTS final training: no test-driven configuration search; official Stage 1 latent loss validation and Stage 2 decoded MAE validation; official Adam/lradj/early-stop; all test rolling windows. Original code remains archived, diffs contain observation/logging/path/resume changes only. Numpy float64 verification is independent of the official metric implementation. Full weights, predictions and raw CSVs stay on the server.
